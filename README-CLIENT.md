# راهنمای سریع راه‌اندازی وب‌سایت عسل باباخُرم 🍯

این راهنما برای اجرای سریع وب‌سایت در محیط لوکال توسعه (`pnpm run dev`) بر روی سیستم ویندوز آماده شده است.

---

### ۱. پیش‌نیازهای اولیه
قبل از شروع، مطمئن شوید نرم‌افزارهای زیر روی سیستم نصب هستند:
1. **Node.js**: نسخه 20 یا بالاتر (دانلود از [nodejs.org](https://nodejs.org))
2. **pnpm**: اگر نصب نیست، دستور زیر را در ترمینال (PowerShell یا CMD) اجرا فرمایید:
   ```bash
   npm install -g pnpm
   ```
3. **دیتابیس PostgreSQL**:
   - **روش ساده (پیشنهادی با داکر):** کافیست Docker Desktop در حال اجرا باشد.
   - **روش بدون داکر:** نصب مستقیم PostgreSQL روی سیستم با مشخصات دیتابیس در فایل `.env`.

---

### ۲. راه‌اندازی خودکار (فقط با ۲ کلیک در ویندوز)
برای راحتی شما دو اسکریپت آماده شده است:

1. روی فایل **`1-setup.bat`** دابل کلیک کنید.
   *(این اسکریپت پکیج‌ها را نصب، دیتابیس را متصل و داده‌های اولیه را وارد می‌کند)*
2. روی فایل **`2-start-dev.bat`** دابل کلیک کنید.
   *(پروژه روی آدرس `http://localhost:3000` باز خواهد شد)*

---

### ۳. یا راه‌اندازی دستی از طریق ترمینال (PowerShell / Terminal)

در پوشه پروژه یک پنجره ترمینال باز کرده و مراحل زیر را وارد کنید:

```bash
# گام اول: روشن کردن دیتابیس لوکال (در صورت داشتن داکر)
docker compose up -d postgres

# گام دوم: نصب پکیج‌های پروژه
pnpm install

# گام سوم: اتصال و همگام‌سازی ساختار دیتابیس
pnpm exec prisma db push

# گام چهارم: بارگذاری اطلاعات و محصولات اولیه
node scripts/seed-db.mjs

# گام پنجم: اجرای سایت
pnpm run dev
```

اکنون مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **http://localhost:3000**

---

### اطلاعات ورود به پنل مدیریت:
- **آدرس پنل مدیریت:** `http://localhost:3000/admin`
- **نام کاربری مدیر:** `admin` (یا شماره موبایل مدیر پیش‌فرض)
- **رمز عبور پیش‌فرض:** در فایل `.env` یا مستندات ادمین تعریف شده است.
